-- Tests that skip on the Windows CI runner (see FILES_TEST_EXPECTED_SKIPS in ci.yml),
-- each as "Test: reason", exactly as the test's Skip call gives them: a listed
-- test that skips for another reason fails the run as an unlisted skip does.
Test_Autonomous_Cleanup_Worker: the stopped-worker half needs Linux and its /proc
Test_Backslash_Executable_Lookup: needs a POSIX host: on Windows a backslash separates directories
Test_Copy_Access_Bits: needs native POSIX mode bits
Test_Cross_Device_Move_Keeps_Setgid: needs native POSIX mode bits
Test_Fifo_Never_Blocks: Windows has no FIFOs
Test_Move_Ownership: no POSIX owning groups here
Test_Recovery_Mode_Failure: recovery records a folder's mode only where mode bits are native
Test_Stray_Home_Trash_Stays_Freedesktop: only Linux and macOS read a ~/.Trash folder; Windows uses the Recycle Bin
Test_Transport_Lease_Claims: a held lease file cannot be replaced here
Test_Trash_Refuses_Volume_Trash: Windows has no freedesktop volume trash
Test_Volume_Trash: Windows has no freedesktop volume trash
